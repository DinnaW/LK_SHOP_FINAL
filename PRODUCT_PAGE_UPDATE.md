# Product Page Update

The storefront now includes a responsive, URL-backed product detail page.

## Included

- Product image/title clicks open the full product page.
- Browser back and forward navigation is supported.
- Product URLs use `?product=product-slug`.
- Existing ZappyMart typography, blue/red palette, spacing and component styling are preserved.
- Product gallery, pricing, KOKO installment line, quantity, wishlist, add-to-cart and buy-now controls.
- Description, specifications and reviews tabs.
- Related Products section.
- Responsive layouts for desktop, tablet and mobile.
- Sidebar/header category links return to the correct homepage section.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
